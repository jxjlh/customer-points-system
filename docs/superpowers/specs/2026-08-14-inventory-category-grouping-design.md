# 库存按 title 类别分组展示

## 目标

在库存列表中，按 `title 类别（大分类）` 将物品分开显示。同一类别可包含多个不同的 `title`，不同类别不再混排在同一张表格中。

## 展示规则

- 每个非空 `title 类别（大分类）` 显示为独立、可折叠的分组。
- 分组标题显示类别名称及该组物品数量。
- 展开后，该组内以表格展示全部匹配物品，并保留现有的编辑、出入库、归档或删除操作。
- 未填写 `title 类别（大分类）` 的物品统一显示在“未分类”分组。
- 现有搜索、存放位置、状态和低库存筛选先执行，再对筛选结果分组。
- 顶部汇总指标和导出继续基于全部筛选结果，不因分组改变统计口径。

## 不在本次范围

- 不修改现有数据库结构或历史值逻辑。
- 不自动根据 `title` 推断或改写 `title 类别（大分类）`。
- 不改变物品新增、编辑、出入库和归档规则。

## 验收标准

1. 不同 `title 类别（大分类）` 的物品显示在不同分组中。
2. 同一类别下的不同 `title` 均出现在同一分组表格内。
3. 空类别物品归入“未分类”。
4. 筛选后空分组不显示，统计与导出仍正确。
